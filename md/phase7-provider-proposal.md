# Phase 7 공급자·모델·비용 제안

조사일: 2026-09-23. 상태: PAUSED — 사용자 요청으로 실제 구현 보류. 아래 내용은 참고용 제안이며 공급자 선정·예산 미확정. 실제 유료 API 호출 없음. [Phase 7 계획](phase7-plan.md)의 D-06/07 검토 자료다.

## 확정된 생성 정책

사용자가 무가이드 생성 허용, 성공 이미지 보존, 부분 실패 표시를 확정했다. 응답 불명은 실패 슬롯 전체 재생성으로 우회하지 않고 기존 PROVIDER_UNKNOWN/과금 미확정 처리를 유지한다. 무가이드 생성과 Phase 8 최종화 허용은 별개다.

## 추천 조합

초기 구현은 Google 유료 Gemini API 하나로 연결하는 안을 권장한다. PDF 분석/규칙 초안은 `gemini-3.8-flash`, 이미지 생성은 `gemini-3.1-flash-image`의 1K를 사용한다. 이는 통합 복잡도와 비용을 고려한 개발 판단이며 실제 브랜드 가이드 품질이 검증됐다는 뜻이 아니다.

- [Gemini 3.8 Flash](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash)는 PDF 입력과 구조화 출력을 지원한다. [문서 이해](https://ai.google.dev/gemini-api/docs/document-processing)를 이용해 페이지 근거와 규칙 초안을 추출한 뒤 사람이 검토/게시한다. 페이지 인용의 정확성은 평가 대상이다.
- [Gemini 3.1 Flash Image](https://ai.google.dev/gemini-api/docs/models/gemini-3.1-flash-image)는 이미지 생성과 비율/해상도 설정을 지원한다. 규칙 JSON 추출은 이 이미지 모델에 맡기지 않는다.
- [Google 공식 가격](https://ai.google.dev/gemini-api/docs/pricing): 3.8 Flash Standard는 2026-12-31까지 100만 토큰당 입력 $0.75, 출력(사고 토큰 포함) $3.75. 2027-01-01부터 각각 $1.50/$7.50로 안내되어 있다. Flash Image 1K 출력은 1장 약 $0.067, 4장은 약 $0.269. 입력·텍스트/사고 출력·세금은 별도다. 유료 tier는 콘텐츠를 제품 개선에 사용하지 않는 것으로 명시되어 있다.

## 평가 예산 및 비용 통제 제안

추천 조합만 우선 평가하며 총 API 사용료 예산은 **USD 20**을 제안한다. 이는 승인 요청액이며 예상 청구액/충전액/운영 월 예산이 아니다. 세금·환율·호스팅은 별도다. 다른 공급자 비교 호출은 이 제안의 기본 실행 대상에 포함하지 않는다.

- 10개 생성 조건 × 4장 = 40장: 1K 이미지 출력만 약 $2.69, 입력 및 사고/텍스트 출력 별도.
- 정상 텍스트/스캔/혼합 PDF 6개, 합계 최대 100페이지: 문서 토큰/출력량에 따라 비용 변동. 참고로 총 입력 100,000·출력 20,000토큰이면 현재 3.8 Flash 요율에서 $0.15이며 페이지당 고정 견적이 아니다.
- 나머지는 품질 수정 후 재평가·추출 반복 여유분이다. timeout/응답 유실/worker 중단 주입은 로컬 test double로 우선 검증하여 불필요한 유료 장애 호출을 피한다.
- 호출 전 입력량/출력 상한/동시 실행 예약 비용을 검사하고 예산 부족이면 신규 dispatch를 차단한다. 공급자 실제 청구가 늦거나 응답이 유실되면 미확정 비용 예약을 유지한다. 대시보드 알림만을 절대 지출 차단으로 간주하지 않는다. 구체 상한 계산은 선정 API 계약 확인 후 구현한다.

## 품질·지연 및 입력 제한 제안

아래 수치는 합의용 목표이며 측정 결과가 아니다.

- PDF 최대 20MiB/50페이지, 암호화·손상 PDF 거절. 추출 결과는 최대 200규칙, 원본/페이지 근거를 보존하고 자동 게시하지 않는다.
- 합성 또는 외부 전송이 허용된 평가 PDF 6개에 정답 규칙을 기록한다. 필수 규칙 재현율 90% 이상, 추출 규칙 근거 정확도 95% 이상, 게시 시 근거 없는 규칙 0건을 목표로 한다. 그림만으로 판단하기 어려운 규칙은 검토 대상으로 남긴다.
- 생성 기본·최대 4장/1K, 장당 파일 10MiB. 정상 평가 10개 요청 중 9개 이상에서 사용자가 채택 가능한 이미지 1장 이상, 디코딩 성공·파일 영속화·지정 비율 검증을 요구한다. 가이드 의미 준수는 사람의 평가이며 Phase 8 검증 통과 배지를 부여하지 않는다.
- 요청 접수 후 대기열 시간을 분리해 실제 실행부터 PDF 추출/4장 생성 각각 5분 이내를 개발 목표로 한다. 기존 timeout 5분 유지, 실제 지연 분포를 보고 후 조정한다.
- 일부 이미지의 안전한 실패와 응답 불명을 구분한다. 성공 이미지는 보존하되 같은 전체 요청을 자동 재호출하지 않는다. 모델과 입력 snapshot, 장별 결과/사용량/공급자 요청 ID를 기록하도록 계약을 설계한다.

## 재개 요청 시 검토할 사항

1. 추천 Google 조합과 위 개발 제한·평가 기준을 채택할지 선택한다.
2. 구현 먼저 진행하고 실제 호출은 보류할지, 준비된 유료 테스트 프로젝트에서 총 $20 범위의 실제 검증까지 허용할지 결정한다.
3. 실제 검증 전 API 키는 서버 환경변수로 설정하고 준비 여부만 확인한다. 채팅/문서에 키를 기록하지 않는다. 외부 전송 가능한 PDF/생성 평가 입력을 확정한다.

공급자/구현 기준이 확정되면 READY 계획 공유 후 구현한다. 계정·실제 호출 승인이 없더라도 로컬 계약/통합 테스트까지 진행할 수 있으나 P7-T05 및 Phase 7 완료는 실제 평가 전까지 차단된다.

2026-09-23: 사용자 요청으로 제안 수준에서 보류했다. 추가 선정 질문이나 구현·유료 검증은 재개 요청 전까지 진행하지 않는다.
