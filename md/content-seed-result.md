# 콘텐츠 검수·가상 샘플 시드 결과

2026-09-25 · **요청 범위 완료 / PASS**

사용자가 승인한 가상 샘플 데이터를 로컬 체험 DB에 입력하고, 한·영 콘텐츠 검수와 최종 확인을 완료했다. 실제 AI 연동·배포 설정·운영 정책은 이번 범위에서 제외했다. 기존 Phase 11 결과를 대체하지 않는 후속 검증이다.

## 입력한 데이터

| 항목 | 수량 | 내용 |
| --- | ---: | --- |
| 가상 파트너 | 6 | 문구·의류·리빙·완구·패키지·디지털 |
| 한·영 파트너 게시 소개 | 12 | 이름·소개·시장 설명, 샘플 표시 |
| 프로젝트 | 3 | 구름친구 문구·파도친구 의류·숲속친구 리빙 |
| 생성 작업 세션 | 3 | 프로젝트별 기획 세션 1개, 생성 결과는 없음 |
| 모니터링 원본 | 2 | 단색 PNG 업로드 fixture, 실제 탐지 결과는 없음 |
| 실제 규칙 기반 추천 | 1 | worker가 계산한 키워드 일치도, 문구 파트너 1위 |
| 프로젝트 커버 | 1 | 브라우저 검사에서 정상 업로드·연결 |

파트너 이름과 소개에 가상 샘플임을 표시했고 실제 연락처·실적·인증을 기재하지 않았다. 규칙 추천 점수는 키워드 일치도이며 AI 분석이나 제휴 성공 확률이 아니다. 모니터링 원본과 커버를 포함해 저장 파일은 원본·썸네일 총 6개다.

## 콘텐츠 검수

- ko/en 랜딩·FAQ·기능 소개에서 실제 생성·검증·PDF 분석·웹 검색은 준비 중 또는 미리보기로 안내했다.
- 추천 설명을 현재 구현된 IP·세계관·브랜드·업종 키워드 비교에 맞췄다. 추천 근거에 AI 분석이라는 표현을 제거했다.
- 팀 협업·권한·우선 지원은 예정 기능으로 표시하고, 협업 문의의 응답 보장 표현을 수정했다.
- 가상 파트너 6개의 한국어·영어 의미와 표기를 확인했다. 사용자 입력인 프로젝트 이름·추천 기준은 언어 변경 때 자동 번역하지 않는다.
- 모바일 390px에서 프로젝트·추천·전체 파트너 목록을 확인했다. [프로젝트 화면](evidence/content-seed/projects-mobile.png) · [추천 화면](evidence/content-seed/partners-mobile.png)

## 시드 동작

별도 `db:seed:demo`는 `claps_demo` 또는 `claps_test` 계열 DB에서만 실행된다. 기존 활성 계정에 정상 로그인하고, 안정된 ID와 DB 잠금으로 동시 실행/재실행 중복을 막는다. 사용자 편집·보관·게시 번역·선호를 덮어쓰지 않는다. 기존 locale-only `db:seed`는 유지한다.

이미지 파일은 기존 업로드 검증과 티켓 처리로 생성한다. 파일을 보존하려면 web과 같은 uploads 볼륨을 쓰는 **worker 서비스**로 실행한다. 초기 검수에서 migrate의 임시 파일 저장소 문제를 발견해, 이번에 생성한 해당 원본 2개만 정리하고 공용 볼륨으로 다시 입력했다. 이후 HTTP 원본 다운로드와 복원 검사가 통과했다.

## 최종 확인

| 검사 | 결과 |
| --- | --- |
| TypeScript·ESLint | 통과, 오류 0; 기존 불필요 eslint-disable 경고 2개 |
| 프로덕션 web·worker·migrate 이미지 빌드 | 통과 |
| 단위 43 + i18n 8 + 통합 115 | **166개 통과** |
| 샘플 Chromium 흐름 | **1개 통과** |
| 시드 동시 실행·중복 방지·편집 보존·계정 격리 | 통과 |
| 한·영 추천·새로고침·모바일·미인증 접근 | 통과 |
| 프로젝트·세션이 있는 DB+파일 백업/빈 환경 복원 | 통과 |

이번 실행에서 자동 테스트는 총 **167개**다. 기존 Phase 11의 전체 브라우저 35개는 이번에 다시 실행하지 않았으며 중복 합산하지 않았다. 프로덕션 web 이미지에서 샘플 전용 브라우저 검사를 실행했다. AI 공급자가 없는 검색 요청은 의도대로 503이며 가짜 결과를 만들지 않는다.

복원 전후 프로젝트 3·세션 3·파트너 6·게시 소개 12·모니터링 2의 전체 행 SHA-256과 파일 6개의 checksum 목록이 일치했다. 복원 환경에서 기존 로그인 세션·한국어 선호·프로젝트 커버·세션 연결·원본 바이트·추천 결과를 확인했다. 복원부터 healthy/HTTP 확인까지 로컬 측정은 **22.34초**이며 운영 SLA를 의미하지 않는다. [복원 증거](evidence/content-seed/recovery.json)
