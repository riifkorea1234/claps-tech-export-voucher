# 최초 관측과 후속 검사

- 기본 캡처 198장을 생성했다. 페이지 JavaScript 예외는 0건이었다. 음수 입력 응답은 제품 계약상 422인데 하네스가 400을 기대한 영어·일본어 검사 2건은 기대값 오류였다. 보정 결과는 supplement-results.json에 기록한다.
- 일본어 프로젝트 편집 버튼의 실제 문구는 `名前を変更`이다. 최초 하네스의 정규식이 이를 놓쳤다. 정확한 문구로 보완 캡처한다.
- 관리자 재인증은 15분당 5회로 제한된다. 시드 재실행과 언어별 관리자 캡처가 같은 증빙 관리자를 사용해 마지막 모바일 요청에서 429를 받았다. 제한을 변경하거나 우회하지 않고 만료 후 같은 계정으로 보완한다.
- PDF 업로드는 HTTP 성공·실제 DB 반영까지 완료됐으나 Playwright response.json()이 응답 본문을 기다렸다. 첫 두 실행은 해당 소유 프로세스만 종료했다. 후속 하네스는 성공 응답과 가이드 조회로 업로드를 확인하고 모든 본문 대기에 제한 시간을 둔다.
- 리뷰 체크박스는 서버 응답 후 체크 상태가 갱신되는 제어 입력이다. Playwright check()의 즉시 상태 검사가 먼저 실패했다. 후속 하네스는 click → HTTP 응답 → 실제 checked 상태 순서로 기다린다. 제품 검사를 끄지 않는다.
- 관리자 jobs의 배경 RSC 요청에서 Cloudflare 502를 1회 관측했다. 같은 시간대 웹 로그에는 `The destination stream closed early`(digest 4025318171)가 있었다. 연결 종료와 관련될 수 있으나 단일 관측만으로 원인을 확정하지 않는다. 실제 관리자 jobs 화면은 캡처됐으며 동일 RSC 경로 5회 재검증과 최종 화면을 보완 결과에 남긴다.
