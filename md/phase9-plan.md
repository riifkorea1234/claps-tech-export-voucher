## 4. 현재 상태 조사

착수 시 기준 폼 이미지/칩/저장은 동작하지 않았고 10개 목업 후보·재매칭 애니메이션만 존재한다. 협업 요청은 이메일 복사다.

2026-09-24 조사: Next 16.3.3 및 로컬 `node_modules/next/dist/docs/01-app/01-getting-started/15-route-handlers.md`를 확인했다. unit/integration/i18n/E2E, DB migration/seed, typecheck 스크립트가 이미 있다. 작업 트리에 Phase 1~8의 다수 미커밋·미추적 변경이 있으며 보존한다.

기존 `users.preferences.matching`은 industries/styles/worldView/collaborationHistory만 지원한다. IP 이름·카테고리·라이선시·매출·참조 파일 계약을 확장해야 한다. 기존 업로드는 project 소유권을 요구하므로 계정 단위 참조 파일을 별도로 처리해야 한다. `storage_tickets.target_type` 확장 시 additive migration과 참조 보존 검사를 함께 적용한다.

파트너 master에는 공개 여부·설명·태그·IP명·시장 설명·이미지·연락처가 있지만 구조화된 가격·팬덤 지표는 없다. 기존 목업의 가격 적합·팬덤 중첩 백분율을 이 데이터만으로 실제 점수라고 표시할 수 없다. 공개 카탈로그 API는 게시 번역을 지원하나 연락처/개별 상세 API 보완이 필요하다. 운영 seed는 locale만 생성하며 공개 가능한 실제 파트너를 제공하지 않는다.

공통 matching job 종류는 있으나 운영 matching handler가 없고 input/output은 기준/파트너 ID만 지원한다. 입력·후보·점수·근거·엔진 버전 snapshot 확장 및 최신 성공 결과 조회가 필요하다.

## 5. 구현 범위

users.preferences.matching 기준·참조 이미지·칩 입력/저장/복원, 추천 adapter·입력/모델 버전 snapshot·종합/4개 항목 점수·설명·Hero·정렬, 재추천 및 이전 결과 유지, 공개 파트너/연락처·ko/en 표시를 구현한다.

이 단계에서 추가·변경하는 사용자/관리자 문구는 ko/en 파일 언어팩에 함께 반영한다. 업무 데이터 번역은 `localized_contents`만 사용하고, 고정 UI·랜딩·메일 문구는 DB로 옮기지 않는다.

## 6. 제외 범위

CRM·인앱 협업 요청·자동 이메일 발송·새 모델 학습. 근거 없는 SHAP/AI 분석 표현은 사용하지 않는다.

결제·구독, 조직 협업, 범용 CMS, 자동 침해 신고는 전체 초기 범위에서 제외한다. 새로운 비용·제품 정책·공개 계약이 필요하면 구현 전에 전체 플랜과 이 문서의 변경 이력을 갱신한다.

## 7. 결정·가정·질문

사용자가 규칙 기반 엔진을 선택했고 점수 의미·필수 입력·상한·계산 시간 검증 기준은 16.1절로 확정했다. 실제 운영 파트너 평가 데이터·사업 품질 기준은 미제공 상태다. 비공개 전환된 파트너는 과거 추천에서도 노출 금지하되 감사 가능한 원본 job 결과는 보존한다.

권장안과 확정 사항을 구분한다. 이 문서 작성에는 추가 승인이 필요하지 않으며, 미결정 항목은 해당 구현의 시작 게이트에서 해결한다. 실제 과금·메일 발송·외부 데이터 변경 검증은 진행 규칙 8.6에 따라 승인된 대상과 환경에서만 수행한다.

## 12. 위험과 대응

고정 파트너 점수와 추천 계산 결과를 혼용하지 않는다. 결과 언어가 요청과 다르면 실제 언어를 표시하고 화면 언어 변경으로 재추천하지 않는다.

## 13. rollback/복구

신규 추천을 제한하고 호환 adapter로 복원한다. 기존 성공 이력 보존·비공개 필터 유지·깨진 신규 결과를 최신 성공으로 대체하지 않는다.

사용자 변경을 포함한 작업 트리를 통째로 초기화하지 않는다. 적용한 migration과 코드 버전의 호환성을 확인하며, 데이터가 존재하는 환경의 파괴적 되돌리기는 백업/복구 검증 없이 실행하지 않는다.

### 16.1 확정 구현 계약

2026-09-24 사용자가 규칙 기반 추천을 선택했다. 외부 공급자/비용 없이 `rules-v1`을 운영 handler로 등록한다. 추천은 사람이 정한 의미적 유사도/성공 확률이 아니라 입력 토큰의 공개 메타데이터 일치율이다. NFKC·소문자·문자/숫자 토큰화, 중복 제거, 정확한 토큰 일치만 사용한다. 4개 항목은 IP(ipName/category→name/ipNames/tags), 세계관(worldView/styles→description/tags), 브랜드(licensee→description/marketDescription/tags), 업종(industries→tags/marketDescription)이다. 입력된 항목마다 일치 토큰 수/전체 입력 토큰 수×100을 반올림하고, 종합은 입력된 항목의 동일 가중 평균이다. 미입력 항목은 null/평가 없음으로 표시한다. 필수 입력은 네 항목 중 최소 하나의 유효 토큰이다. 매출·이력·이미지는 저장하되 근거 데이터 부족으로 점수에 사용하지 않는다.

공개 후보 최대 200개, 결과 최대 20개, 동점은 ID 오름차순, 종합 0점 후보 제외. 200개 초과 시 일부 후보를 임의 선택하지 않고 제한 오류를 반환한다. 입력과 후보 텍스트/버전 snapshot은 job에 저장하며 metadata 64KiB 한도를 유지한다. 동일 계정 진행 추천 1개, 기존 시간당 60회 제한, matching timeout 30초. 화면 언어 변경은 재추천하지 않는다. 최신 성공 결과와 최근 시도 상태를 별도로 반환한다.

기준은 revision으로 동시 수정 손실을 방지한다. 참조 업로드는 기존 디코딩/ledger를 확장하고 matching target을 additive migration으로 추가한다. 타인 참조·만료·제거 파일 조회를 거절하고 과거 job의 파일 참조를 보존한다. 공개 카탈로그의 실제 DB 데이터를 사용하며 임의 운영 seed는 추가하지 않는다.

검증 기준: 합성 A/B 코퍼스의 예상 1위/정확한 점수/결정적 정렬/무근거 제외, 200개 후보 계산 1초 미만, 실제 DB·worker·브라우저에서 저장→재추천→실패/비공개/격리 확인. 합성 평가 PASS와 실제 파트너 데이터의 사업 품질 검수를 별도 기록한다. 실제 운영 데이터 미제공 시 전체 완료 판정은 보류한다.
