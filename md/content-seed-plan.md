# 콘텐츠 검수·샘플 시드·최종 확인 계획

2026-09-25, COMPLETE. 사용자 승인: 가상 샘플 파트너/프로젝트와 콘텐츠 검수·최종 확인. 실제 AI·배포 설정·운영 정책은 제외한다. 기존 Phase11 결과는 유지하고 이번 추가 검증은 [결과 보고서](content-seed-result.md)에 기록했다.

- 기본 locale-only seed는 유지. 명시적 demo seed에 공개 샘플 파트너6/ko·en 게시12, 계정별 프로젝트3/세션3/모니터링 원본2/추천 기준을 추가한다.
- claps_demo 또는 claps_test 계열 DB에서만 실행. 기존 active 계정으로 로그인하며 사용자·관리자 자동 생성/권한 승격을 하지 않는다. 최초 로컬 체험 계정은 별도 정상 가입·sandbox 확인·프로필 절차로 만든다.
- 안정된 ID와 advisory lock, insert-only 처리로 재실행/동시 실행 시 중복 방지. 사용자 편집/게시/보관/선호는 덮어쓰지 않는다. 파일은 기존 upload ledger/이미지 검사를 거친다. AI 성공 job·검증 결과·가짜 탐지 결과는 넣지 않는다.
- ko/en 소개의 의미 일치, 빈 필드/샘플 표시/연락처 허위 기재, 랜딩의 현재 미제공 기능 설명을 검수한다. 법률 문서/운영 정책은 작성하지 않는다.
- 테스트: seed 멱등·동시 실행·편집 보존·계정 격리·권한, i18n/static/build, 실제 HTTP/Chromium 추천/원본/새로고침/모바일, **프로젝트·세션이 들어 있는 DB+파일** 백업/빈 환경 복구.
- 기존 사용자 변경을 보존. 샘플 데이터는 로컬 체험 DB에 남기며 비밀번호/세션은 보고서·Git에 넣지 않는다.
